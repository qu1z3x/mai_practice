# Самолеты - индексная сортировка

Программа читает данные о самолетах из файла, проверяет строки и печатает таблицу по времени посадки

## Как устроена программа

`isEmptyLine` - проверяет пустую строку

`isDigit` - проверяет цифру

`parseTime` - проверяет время

`isGoodBoardNumber` - проверяет борт

`parsePlane` - разбирает строку

`addError` - добавляет ошибку в список

`checkPlaneLogic` - проверяет дубли и модель борта

`loadPlanes` - читает файл

`sortIndexesByTime` - сортирует индексы

`printTable` - печатает таблицу

Ошибки копятся, но таблица всё равно строится по корректным строкам

Если строка плохая, она не попадает в таблицу

## Главное

Массив структур не сортируется

Сортируется только индексный массив:

```cpp
int indexes[MAX_PLANES];
```

Вывод идет через индекс:

```cpp
planes[indexes[i]]
```

То есть сортировка идет через индексы, а не через сами записи

## Входные данные

Файл по умолчанию `planes.txt`

Одна строка - один самолет:

```text
13:25 МС-21 Б-3051 Нижний Новгород
```

Поля:

```text
время марка бортовой_номер пункт_отправления
```

Бортовой номер строго в формате `Б-хххх`

Пункт отправления читается до конца строки

Можно писать `Нижний Новгород`, `Санкт-Петербург` или `Нижний_Новгород`

Проверяется, что один борт не повторяется в одно и то же время и не меняет модель

## Тестовые файлы

`planes.txt` - основной пример

`planes_positive.txt` - только корректные строки

`planes_negative.txt` - только плохие кейсы

`planes_mixed.txt` - ошибки плюс нормальные записи

`planes_boundary.txt` - граничные значения времени и борта

## Запуск

Обычно программа берет данные из `planes.txt`

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o main
./main
```

С другим файлом:

```bash
./main my_planes.txt
```

Например:

```bash
./main planes_positive.txt
./main planes_negative.txt
./main planes_mixed.txt
./main planes_boundary.txt
```
